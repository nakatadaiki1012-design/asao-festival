🎪 出し物の管理画面

文化祭の案内マップに出す「どこで・どんな出し物をやるか」を確認・管理するページです。

① 出し物を書きこむ（編集する）

出し物の内容は Google スプレッドシート に書きこみます。書きこむと、数分で案内マップに反映されます（プログラムの知識はいりません）。

読み込み中…

📮 紹介文と写真の受付フォーム

各団体には Google フォーム で紹介文と写真を送ってもらえます。送られた内容は、「団体名」が同じ行に自動ではまり、地図に出ます（同じ団体が何回送っても、いちばん新しい回答が使われます）。

フォームの「団体名」の選択肢にする一覧（コピーして貼りつけ）

フォームの「団体名」の質問を「プルダウン」にして、1つ目の選択肢の欄にこの一覧をまとめて貼ると、全部が選択肢になります。名前の書きまちがいがなくなるので確実です。

② 書きこんだ内容のチェック

「場所」がマップのどこになったかを確認できます。❌ や ⚠️ が出たら、下の「④ 場所の一覧」の名前をそのまま「場所」の列に書いてください。

🗺️ 案内マップを開く

③ スプレッドシートの書きかた

1行目は見出し、2行目から1行に1つの出し物を書きます。見出しは次のとおりです（ひな形をダウンロードして、スプレッドシートの「ファイル → インポート」で読みこむと楽です）。

見出し書くこと例
場所出し物をやる場所。下の「④ 場所の一覧」の名前。クラスは「2-4」でもOK。同じ名前が別の階にあるときは「2階 図書室」のように階も書く2-4 ／ 化学実験室 ／ 体育館 ／ 中庭
団体名クラス・部活などの名前2年4組 ／ 科学部
出し物名出し物のタイトル（地図の上にも出ます。短めがおすすめ）お化け屋敷
ジャンル下の色分けのどれか（ほかの言葉はすべて「その他」の色）
時間やっている時間（セルの中で改行してもOK）10:00〜15:00
説明くわしい紹介本格的なお化け屋敷です！
画像（なくてもOK）画像の URL。Google ドライブの画像は「リンクを知っている全員」に共有したリンクを貼るhttps://drive.google.com/file/d/…
非表示（なくてもOK）「○」を書くと、その行はマップに出さない（準備中のときなど）○

④ 場所の一覧

「場所」の列にはこの名前をそのまま書くと確実です。同じ階に同じ名前の部屋が2つ以上あるときは、右の記号（例：F1-AP15）を書いてください。

はじめての準備（最初に1回だけ。管理する人がやること）
  1. Google ドライブで新しい Google スプレッドシート を作り、上のひな形を「ファイル → インポート → アップロード」で読みこむ（「現在のシートを置換」）。
  2. 右上の 「共有」 → 「一般的なアクセス」を 「リンクを知っている全員」・「閲覧者」 にする（マップが内容を読むために必要です。書きかえはできません）。
  3. 書きこんでほしい人（実行委員など）を「共有」の「ユーザーやグループを追加」で 「編集者」 として追加する。
    → 編集できるのは、ここで追加した人だけです。
  4. スプレッドシートの URL（ブラウザのアドレス欄）をコピーして、GitHub の js/festival-config.js の sheetUrl: "" の "" の中に貼って保存する。
  5. このページを開き直して、「② チェック」にスプレッドシートの内容が出れば完了です。
フォームの準備（紹介文と写真を各団体に送ってもらうとき。最初に1回だけ）
  1. 出し物の表のスプレッドシートを開き、「ツール → フォームを作成」で新しいフォームを作る（回答が同じスプレッドシートの新しいシート（タブ）にたまるようになります）。
  2. 次の質問を作る（質問の名前に、この言葉が入っていればOK）：
    • 団体名（プルダウン・必須）… 選択肢は上の「団体名の選択肢にする一覧」をコピーして貼る
    • 紹介文（段落）
    • 画像（ファイルのアップロード・「画像」だけ許可・最大5枚くらい）
    • （なくてもOK）出し物名・時間 … 書いたときだけ表の内容を上書きします
  3. Google ドライブで、フォームの写真がたまるフォルダ（「（フォーム名）（File responses）」）を右クリック →「共有」→ 「リンクを知っている全員」・「閲覧者」 にする（地図に写真を出すために必要です）。
  4. スプレッドシートの 回答のシート（タブ） を開いて、アドレス欄の URL を js/festival-config.js の formSheetUrl に、フォームの「送信 → 🔗」の URL を formUrl に貼って保存する。
  5. テストで1回送ってみて、上の「② チェック」の「フォーム」の列が「✅ 受付済」になれば完了です。

※ ファイルのアップロードの質問があるフォームは、答える人が Google アカウントにログインする必要があります（学校のアカウントで大丈夫です）。
※ 送られた内容はすぐ地図に出ます。出したくない出し物は、出し物の表の「非表示」の列に ○ を書くと隠せます。

（メモ）スプレッドシートを使わないとき

スプレッドシートを使わないときは、このリポジトリの data/exhibits.csv を GitHub 上で直接書きかえても反映されます。
